El 4 de agosto tuvimos el placer de compartir un nuevo taller en la comunidad RLadies Buenos Aires, esta vez de la mano de Jesi Formoso, quien nos introdujo al fascinante mundo de Quarto. Quarto es un sistema de publicación de código abierto que amplía las capacidades de RMarkdown, permitiéndonos crear documentos científicos y técnicos que combinan código, texto e interacción. Durante el encuentro, Jesi nos mostró cómo Quarto nos permite generar informes reproducibles, presentaciones y hasta sitios web. Trabajamos con ejemplos prácticos que nos ayudaron a comprender cómo integrar texto explicativo y código ejecutable en un mismo flujo de trabajo, cómo personalizar los formatos de salida y cómo aprovechar los parámetros para crear diferentes versiones de un mismo documento. El taller fue introductorio y pensado para personas con conocimientos básicos de R pero poca o ninguna experiencia previa con Quarto.

### 🎯 Objetivos de aprendizaje

-   Familiarizarnos con Quarto como herramienta de publicación dinámica y reproducible.

-   Identificar sus posibilidades para la creación de documentos técnicos (informes, presentaciones, sitios web).

-   Explorar la combinación de texto y código en informes que se actualizan automáticamente.

-   Aprender a usar parámetros en Quarto para crear variantes de un documento de manera eficiente.

Toda la info en el repo del proyecto [aquí](https://jformoso.github.io/quarto-rladiesBA/)
